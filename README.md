The main purpose of this project is to implement a multithreaded dictionary server based on a modern client-server architecture. These servers must be capable of handling multiple client requests at the same time by ensuring the reliability of communication using the TCP protocol. It is important to support users to smoothly perform tasks such as searching for the meaning of words, adding new words to the dictionary, and deleting existing words. These tasks greatly improve the accessibility and utilization of information and contribute to maximizing the user experience.
To realize this, this project actively utilizes the concepts of socket programming and multi-threading. Through socket programming, communication paths are established between servers and clients, and multi-threading is used to effectively process requests from multiple clients at the same time. In this process, each client's request is processed in an individual thread, aiming to minimize the server's response time and maximize processing efficiency.
In addition, securing the reliability of network communication is an important factor in this project. The TCP protocol ensures that information is accurately transmitted and received by ensuring the reliability and sequence of data transmission and verifying the integrity of data. This ensures that stable communication can be achieved without loss of information when a user sends a request to a server, no matter what network problems arise.
